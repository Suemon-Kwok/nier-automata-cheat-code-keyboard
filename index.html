NieR:Automata PC notes

The final cheat code, on keyboard and mouse

NieR:Automata’s hidden “skip to the ending” cheat only listens to gamepad buttons. This guide shows how to give it what it wants using a keyboard, a mouse and three free tools, with a screenshot for every step.

Short version

The cheat is real and it works on the PC version. The game checks it using the raw state of a gamepad, so the keyboard-and-mouse controls in the game’s own settings cannot enter it. The workaround is to make Windows believe an Xbox controller is plugged in, and to drive that controller from your keyboard and mouse.

That takes three free tools:

  • ViGEmBus creates the virtual Xbox controller.
  • UCR (Universal Control Remapper) turns your key presses into that controller’s buttons.
  • Interception lets UCR see your keyboard and mouse, and hide the real key presses from the game.

The final trick is the right trigger. The code needs R2 (RT on Xbox) held down for the whole sequence, and the obvious way of mapping it lets go after a moment. Step 6 shows the version that holds.

What a successful run looks like

Hold the right trigger, tap nine buttons, and the screen fades to black and jumps to the final ending. That ending unlocks chapter select, the debug room and the trophy shop. At the very end the game offers to delete your save data. Say no.

The code and where it works

The code was found by the data miner Lance McDonald in January 2021, after the game’s director hinted that a final secret was still undiscovered. It is a controller sequence: hold R2, then press the nine buttons in order.

Where and when

  • Where: the prologue, in the large open area where you fight the first boss (Marx). Stand between the two sets of three barrels.
  • When: after Marx is defeated and the short conversation with 9S has ended, and before you walk into the factory. Lance’s video says that once the doors close and the forced fight starts, the chance is gone.
  • How close: the game checks your distance from one spot. In our build the limit was 1.5 (Lance’s notes call these metres).
  • How fast: Lance’s notes say the entry resets after 5 seconds. In our build the game’s timer restarted after every button press, and our successful run took 7.4 seconds from the first press to the last. About one press per second worked.

Why the keyboard alone fails

The obvious plan is to set up the keyboard so that every code button has a key. That runs into one problem straight away: R2 is Evade in the Type A layout, and the keyboard list has no Evade key.

The rest of the game’s keyboard list

What we measured

To check this properly we read the game’s own input values while it was running. This was read-only, and nothing was written to the game. The method and tools are in the proof section.

  • With a virtual controller running, each button produced its own distinct value, and the right trigger produced a held value.
  • With the keyboard only (no virtual controller), pressing the keys that switch weapons, attack, jump and so on changed nothing in those values in our test. The log was empty.

That was one test session on one Steam build, so treat it as strong evidence, not a guarantee for every version of the game.

Why not Steam Input?

Steam’s controller settings can remap a controller, but they need one to be connected before they open. With nothing plugged in, the screen below is all you get, and you cannot turn a keyboard into a controller from inside it.

Before you start

What you need

  • Windows 10 or 11 (64-bit), with an administrator account.
  • NieR:Automata on Steam. We tested the Game of the Year edition.
  • A keyboard and a mouse with a middle button. A side button works too.
  • One restart of Windows part way through.

Read these first

Back up your saves

The cheat ends with an offer to delete your save data. Copy the folder Documents\My Games\NieR_Automata somewhere safe before you start, and use a new save slot for the run.

Interception is a driver

It watches your keyboard and mouse at a low level. That is how it can block keys, and it is also why some online games with anti-cheat refuse to run while it is installed. NieR:Automata is single-player, but if you play those games, uninstall it afterwards. Undo everything has the steps.

The tools are old

ViGEmBus is retired and its repository is archived. UCR’s last release is a 2020 alpha. Both still worked for us, but expect rough edges and download only from the official pages linked in each step.

1Install ViGEmBus

ViGEmBus is the driver that creates a virtual Xbox 360 controller. UCR plugs its buttons into that controller.

  1. Open github.com/nefarius/ViGEmBus/releases.
  2. Under Assets on the latest release (1.22.0), download ViGEmBus_1.22.0_x64_x86_arm64.exe. Skip the two “Source code” files.
  3. Right-click the downloaded file, choose Run as administrator, and click through the installer with the default options.
  4. Restart Windows if the installer asks you to.

You can check the install worked in Device Manager. A ViGEm / Nefarius virtual gamepad bus should appear under System devices. UCR will also confirm it in step 4, when the virtual controller shows up in its output list.

2Install UCR

UCR (Universal Control Remapper) is the program where you say “this key presses that controller button”.

  1. Open github.com/Snoothy/UCR/releases.
  2. On the latest release (v0.9.0 Alpha), download UCR_v0.9.0.zip from Assets.
  3. Right-click the zip, choose Extract All, and extract to a normal folder such as your Desktop. Do not run it from inside the zip.
  4. Open the folder and double-click UCR.exe.
  5. UCR asks whether to unblock its files. Click Yes.
  6. A console window says it unblocked the files. Press any key to close it, then double-click UCR.exe again.

3Install Interception and restart

UCR reads keyboard and mouse input through a driver called Interception. Without it, UCR’s input list is empty. This is the step where most people get stuck, because the installer does nothing if you double-click it.

  1. Open github.com/oblitum/Interception and click the latest release (v1.0.1) under Releases.
  2. Download Interception.zip from Assets, not the source code.
  3. Extract it and open the command line installer folder inside. You should see install-interception.exe.
  4. Press Win + X and choose Terminal (Admin). Click Yes on the Windows prompt. The title bar should say Administrator.
  5. Run the installer with /install. In PowerShell, which is what the admin terminal opens, the command needs an & in front. Replace the path with your own:
& "C:\Users\YOU\Desktop\Interception\command line installer\install-interception.exe" /install

In a plain Command Prompt, leave out the &:

"C:\Users\YOU\Desktop\Interception\command line installer\install-interception.exe" /install

You should see this message. Restart Windows before continuing.

Common mistakes with this installer
  • Double-clicking the installer. It only prints its usage text and closes. Windows may then say the program might not have installed correctly (screenshot below). Nothing was installed. Use the admin terminal.
  • Missing the space before /install. Write …install-interception.exe" /install, with a space after the closing quote.
  • A terminal that is not elevated. The installer needs administrator rights. Open the terminal with Win + X and Terminal (Admin).
  • Forgetting to restart. UCR will not list your keyboard until you do.

4Create the UCR profile

A profile says which devices UCR listens to and which virtual controller it writes to.

  1. Open UCR.exe and click the person with a plus icon at the top of the Profiles panel. Name the profile anything. Click it in the list.
  2. You now see Input devices and Output devices panels. In Output devices, click +, tick ViGEm Xbox 360 Controller 1 and click ADD. Pick only this one. UCR’s own wiki warns that several emulated Xbox controllers are not properly supported.
  3. In Input devices, click +. If the list is empty, Interception is not installed or you have not restarted.
  4. Tick your keyboard and your mouse (entries starting with K: and M:) and click ADD. Names depend on your hardware. If you are not sure which is which, add one, finish step 5, and see whether your key presses register.
  5. Click the save icon.

5Bind the keys, and block the real ones

Add one mapping per key

  1. Open the profile editor from the icons in the profile’s header (the person-with-a-pencil icon opened it for us). The Plugins panel lists categories.
  2. Under Button, click + next to Button to Button.
  3. In the new mapping, click Click to bind under Input and press the key.
  4. Under Output, click Click to bind, then choose the controller button from the menu (DPad or Buttons).
  5. Repeat for each row below. The pencil icon on the mapping’s blue header lets you rename it.

Turn on blocking

With blocking off, the game receives your real key presses as well as the controller buttons. We turned blocking on while troubleshooting, and did not test the final run without it. It removes a variable, and it also stops letters appearing in other windows while the profile runs. It takes two parts.

  1. Close UCR. Open UCR\Providers\Core_Interception\Settings.xml in Notepad and make sure BlockingEnabled has the value true.
  2. Start UCR and open the editor. Each input now has a Block switch. Turn it on for every key mapping.
All the mappings, with Block on

Check that blocking works

  1. Click save, then the Play button (the triangle) in UCR’s toolbar.
  2. Open Notepad and type I K U O.
  3. Nothing should appear. If letters appear, blocking is not on. Check the file and the switches again.

6Bind the right trigger

This took the longest to get right. The code needs R2 held down for the entire sequence, and the game clears its progress whenever R2 is released. The plugin you pick decides whether the virtual trigger stays down.

Use this plugin

In the Plugins panel, under Axis, click + next to Button to Axis (“Map from one button to different axis values”). It is the single-button plugin. Do not use Buttons to Axis (plural) or Axis to Button.

  1. Add the Button to Axis mapping and rename it “right trigger” if you like.
  2. Input: choose your mouse in the device list, click Click to bind, and press the middle mouse button (or a side button). Avoid the left and right buttons, because blocking them makes the mouse awkward to use.
  3. Output: click Click to bind, choose Axes, then RT.
  4. In the plugin’s settings, make the released value 0 and the pressed value full (100). UCR’s guide for this plugin calls them “Axis on release” and “Axis when pressed”, and its release notes mention an absolute-value option for Xbox triggers. We did not capture this settings screen, so use the test below to confirm the values.
  5. Save, press Play, and run the test in step 7. Hold the button for ten seconds and watch the bar.

What it should do: the Z Axis bar should jump to its far end when you press the button, stay there for the whole time you hold it, and return to the middle when you let go.

What did not work, with the evidence

The first attempt used the two-button Buttons to Axis plugin with Z as the “high” key. R2 registered for a moment and then released while the key was still down. We ran three tests to find out why. In every one the bar went to the end on the press and drifted back to the middle during the hold.

Wrong plugin: Axis to Button

Two-button plugin with a key

Same plugin with Left Shift (rules out key auto-repeat?)

We suspected Windows’ key repeat. Left Shift, which does not auto-repeat the same way, behaved identically.

Same plugin with a mouse button (no key repeat at all)

A mouse button cannot auto-repeat, and it still released. That pointed at the plugin, not the keyboard.

Switching to the single-button Button to Axis plugin fixed it.

7Test the virtual controller

  3. You should see Controller (XBOX 360 For Windows) with status OK. Select it and click Properties, then open the Test tab.

8Set up NieR:Automata

Settings that matter

  • Steam Input: in Steam, right-click NieR:Automata, choose Properties, then Controller, and leave the override on Use default settings. We set it back to default after trying Enable, and did not test whether Enable breaks the code.
  • Special K / FAR: we ran with it turned off, by renaming dxgi.dll to dxgi.dll.off in the game folder. We turned it off to remove a variable and did not test whether it matters.
  • Controls: use the Type A layout.
  • Stop 2B from dodging. In Controls, choose Custom, and give RT a harmless function, for example by swapping Evade with Toggle Light. Do the same for X and Y if you find the attacks move 2B, for example with Lock-on and Reset Camera. When R2 goes down, 2B would otherwise dodge straight out of the circle.
  • Use a new save slot. Start a fresh game, because you will need to play the prologue anyway and the code may end with a deletion offer.

The order matters

Once the game sees the virtual controller, it stops listening to the keyboard and mouse. We could not even press Esc in the game afterwards. If you start the profile first, the menu may refuse to close. So do it in this order:

  1. Open UCR and make sure the profile is stopped.
  2. Start NieR:Automata and play the prologue with the keyboard and mouse until you are in position (step 9).
  3. Alt+Tab to UCR, press Play, and Alt+Tab back.
  4. The game pauses when it loses focus, so its menu is showing. Press O (the controller’s B) to close it. If you cannot close it, press Stop in UCR and the keyboard comes back.

9Enter the code

  1. Beat Marx, watch the short 9S conversation, and walk 2B to the spot between the two sets of three barrels. Stand still. Do not walk into the factory.
  2. Start the UCR profile, return to the game and close the menu, as in step 8.
  3. Press and hold the middle mouse button (R2).
  4. About one second later, with R2 still held, tap I K I L J U O Y H, roughly one per second.
  5. Keep holding the middle button for a few more seconds, until the screen fades to black.

How our successful run went

R2 went down at 2.1 seconds. The nine buttons followed from 4.0 to 11.3 seconds, roughly one a second, and the game started loading the ending at 13.9 seconds. The full log is in the proof section.

Do not use the pause menu trick from Lance’s video. On our setup, the Shortcuts menu closes when you press B, and the code needs B as button seven.

After the cheat

Decline any prompt about deleting your save data

At the end of the ending sequence the game asks whether to delete your save data to help other players. Say no. It is a real deletion. Back up Documents\My Games\NieR_Automata first anyway.

Other players report that declining keeps everything. Twinfinite says that keeping your save keeps chapter select, the debug room and the post-game bonuses. Kotaku says there is no penalty for not deleting. One Steam discussion reports the deletion request only appears if you choose to leave a message for other players.

Getting back to the barrels

The prologue cannot be saved, so to try again you either start another new game or use chapter select. Lance’s video says that, once chapter select is unlocked, chapter 1-2_3 (“2B inside the factory”) skips to this part. We have not tested where that chapter starts, so check that you arrive before the 9S conversation.

If the code still does nothing

  • Are you in the prologue arena, after the 9S conversation, between the two sets of three barrels, and not in the factory?

Proof from the game’s code

These are the notes behind the guide. They matter only if you want to check our claims or adapt the method to another build. Everything here was read from the running game and nothing was written to it.

What the cheat function does in our build

We found the function by searching the game’s memory for the two coordinate values in Lance’s notes. The numbers below are from the Steam build whose NieRAutomata.exe image size is 0x18f7000. They will differ in other builds.

CheckWhat we found
Game stateA state value must equal 0x100 (it read 0x100 in gameplay)
MapThe current map name must match 00_80_A_RobotM_Pro_1stArea
R2Bit 0x4000 must be set in a held-button value
PositionWithin 1.5 of X = −665 and Z = 473.69. Height is ignored. Lance’s notes show 493.69 for Z, so his build differed or his notes had a typo.
PressesEach new button press is stored in a list that holds up to 20. A timer restarts on every press and clears the list after 5 seconds without one.
MatchThe last nine presses are compared with a stored code (below)
ResultOn a match the game loads the ending scene named BackTitle_FIN

The stored code was found in memory as nine values: 8 4 8 2 1 40 20 80 10.

The scripts we used

Three small Python scripts read the game’s memory without writing to it. They need Python 64-bit and install pymem and capstone on first run. The addresses inside them are for the build described above and the scripts refuse to run on a different one.

  • find_cheat_code_v2.py finds the cheat function by its coordinate constants and writes a disassembly report.
  • watch_cheat_inputs.py logs the held and pressed button values the cheat reads.
  • watch_cheat_manager.py finds the cheat object and logs its press counter, timer and fired flag.

Undo everything

  1. UCR: press Stop, close it, and delete its folder.
  2. Interception: open an admin terminal in the installer folder and run the same command with /uninstall, then restart Windows.
& "C:\Users\YOU\Desktop\Interception\command line installer\install-interception.exe" /uninstall
  1. ViGEmBus: in Windows Settings, open Apps, find the ViGEm / Nefarius entry, and uninstall it.
  2. The game: if you use Special K, rename dxgi.dll.off back to dxgi.dll. Switch the controls layout back from Custom.
